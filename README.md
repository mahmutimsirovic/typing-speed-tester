# Typing Speed Tester ⌨️⚡🚀

A fun and lightweight web app built with **HTML, CSS, and JavaScript** that measures your typing speed and accuracy in real time. 🎯⌨️

## ✨ Features
- 📄 Random sentence generation  
- ⚡ Live WPM (words per minute) tracking  
- 🎯 Accuracy calculation  
- 🛑 Stop and 🔄 Restart controls  
- 🏁 Final results summary (speed, accuracy, time)
